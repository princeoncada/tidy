# ChatGPT Support Checklist

Support checklist for ChatGPT work in Tidy.

Use this file for second-opinion review only.

## Checks

- State whether review is remote-only or includes pasted local evidence.
- Look for stale assumptions, wrong paths, duplicate truth, role drift, validation-boundary drift, and roadmap mismatch.
- Do not act as the default product-code implementer.
- When explicitly assigned docs or workflow edits, keep them scoped and reviewable.
